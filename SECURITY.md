# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Report them privately through GitHub's
[private vulnerability reporting](https://github.com/thruputchain/thruput-protocol-ts/security/advisories/new)
for this repository.

Include the affected package and version, a description of the issue, and
steps or input that reproduce it. Serialization bugs are especially relevant:
for example, input that decodes differently here than in the Rust
implementation, or input that causes excessive memory use or a crash when
decoded.

## Supported versions

Fixes are released in the latest published version of the `@thruputchain/*`
packages.
